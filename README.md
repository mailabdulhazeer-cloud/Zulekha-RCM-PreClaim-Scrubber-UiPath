# Zulekha-RCM-PreClaim-Scrubber-UiPath
Automated Healthcare RCM Pre-Claim Scrubbing &amp; Validation Dispatcher built in UiPath Studio (VB.NET). Validates HIS outpatient Excel exports (UAE Emirates ID Regex, ICD-10 codes, and TPA Prior Approvals for Daman, Nextcare, Neuron, NAS, and Sukoon) prior to DHA eClaimLink / Riayati XML submission.
